Get your changes out of the browser and into the repository.

Publish to the live site

Until the admin backend is built, edits live in this browser only — they show on the shop on this machine, but nobody else sees them. To publish for real, download products.js below and replace assets/js/products.js in the repository, then run ./setup.sh to commit and push.

Photos you upload are held in this browser rather than sent anywhere, so they don't survive the export. Once the backend is in place the same upload box will send the file to storage and save the address it returns, and photos will publish with everything else.

Load a catalogue

Import a JSON file in the same shape as the export. This replaces everything currently listed.
